Required files for this project (place in this folder: site/assets/)

Backgrounds
- gm_hero.webp (recommended: 2400x1500)
- gm_support_01.webp (recommended: 2000x1300)
- gm_support_02.webp (recommended: 2000x1300)
- tf_hero.webp (recommended: 2400x1500)
- tf_support_01.webp (recommended: 2000x1300)
- tf_support_02.webp (recommended: 2000x1300)

Covers
- cover_graduation.webp (recommended: 1200x1200)
- cover_timeout.webp (recommended: 1200x1200)

Textures
- tex_grain.png (tile: 512x512 or 1024x1024)
- tex_paper.jpg (recommended: 2200x1400)

UI icons
- ui_burger.svg (optional fallback already handled in JS)
- ui_close.svg (optional fallback already handled in JS)

Notes
- If image files are missing, panel backgrounds still render using gradient fallbacks.
- If icon SVGs are missing, menu buttons fall back to text symbols.
- Keep filenames exact (case-sensitive on some hosts).
